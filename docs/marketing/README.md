# Graphics for the product pages

`matter_graphics.py` (with `homey_graphics.py` for the shared drawing code) renders the hero (1600×700, SMART and OFFICE)
and the step graphic (1600×560) in the 11 shop languages. It needs the Südwind logo as `assets/logo.svg.png` and the
product images `assets/smart.jpg` and `assets/office.jpg` (cover images from the shop, not in this repository).
The names of third-party systems appear as plain text only, no third-party logo.
